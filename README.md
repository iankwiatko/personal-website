# Personal Website

## Overview

This is my personal website to display personal projects in one neat place. Features will be added as time goes on.

## Authors

Ian Kwiatkowski

## Features

- **Introduction**: Card introduces me and provides a little background along with nav to sections.
- **Projects**: Projects section contains my GitHub card, along with cards for each of my projects. The projects contain tags with links to the source code and website if it is hosted and the technologies used in the project.
- **Contact**: Contains tiles with my contact info.

## how to run locally

1. do `npm install` to install all the dependencies
2. do `npm start` to run

- to view the app in your browser, open [http://localhost:3000](http://localhost:3000)
